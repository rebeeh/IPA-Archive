# Contributing to IPA Archive

[🏠 Home](README.md) • [📚 Guides Index](README.md#-documentation-index)

---

Thank you for your interest in contributing to **IPA Archive**! Community contributions help keep version lookups, CLI instructions, and troubleshooting guides accurate and up-to-date.

---

## Code of Conduct & Ethical Research

1. **Research & Documentation Focus**:
   - This project documents legitimate package acquisition using Apple's official Storefront APIs and personal account credentials.
   - **Do NOT submit**:
     - Pre-downloaded proprietary `.ipa` binaries.
     - Cracks, FairPlay circumvention tools, or patched binaries.
     - Stolen or shared Apple ID credentials.
2. **Respect Terms of Service**:
   - Emphasize legitimate software testing, compatibility verification, and digital preservation.

---

## How You Can Contribute

- **Report Storefront Regressions**: Document changes to Apple's API endpoints or issues in tools like [`ipatool`](https://github.com/majd/ipatool) or [`AppManager`](https://git.kawaiizenbo.me/kawaiizenbo/AppManager).
- **Expand Guides**: Add guides for macOS/Linux workflows, command-line scripts, or alternative tools.
- **Improve Troubleshooting**: Document new error codes or edge-case behaviors observed in the wild.

---

## Submission Process

1. Fork the repository on GitHub.
2. Create a feature branch (`git checkout -b feature/update-guide`).
3. Commit your changes with clear, descriptive commit messages.
4. Push to your branch and submit a Pull Request.
