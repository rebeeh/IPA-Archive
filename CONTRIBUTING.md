# Contributing to IPA Archive

We welcome community contributions that expand documentation, add installation methods, or document store behavior.

## Contribution Guidelines

1. **Research & Educational Focus**: Submissions must adhere strictly to research and documentation. Do not commit proprietary IPA binaries, cracks, or DRM-bypass tools.
2. **Accurate Commands**: Verify commands against modern releases of documented tools (e.g., `ipatool` 2.8+).
3. **Clarity**: Maintain structured markdown formatting with clear headings, prerequisite lists, and code blocks.
